# AI in Practice / AI w praktyce

Reviewed content lives in `data/ai-practice.json`. The four generated pages use `ai-practice.css` and `ai-practice.js`, with the existing website header, tabs and footer. To add a new review, append an entry with a new slug, date, video ID, preview image and a localised card and article in the same structure as episode 01; update the upcoming preview, run `node scripts/build_ai_practice.mjs`, add both canonical review URLs to sitemap.xml and run `npm test` before publication. Images belong under assets/ai-practice; strip metadata and review privacy before adding them. Only link the real YouTube video ID, never autoplay before a visitor clicks. Keep the original PL editorial approval and natural British English copy aligned. No newsletter subscription or QR FINDER changes are needed.
